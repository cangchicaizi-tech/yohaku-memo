# 余白メモ

フォルダ分け(入れ子も可)・自動保存・テキスト書き出しに対応した、シンプルなメモアプリです。
サーバーは不要で、メモはお使いのブラウザの中に保存されます。

## ファイル

| ファイル | 役割 |
| --- | --- |
| `index.html` | アプリ本体 |
| `manifest.webmanifest` | ホーム画面に追加するときの名前・アイコン設定 |
| `sw.js` | オフラインで開くための設定 |
| `icon-192.png` / `icon-512.png` | Android 用アイコン |
| `apple-touch-icon.png` | iPhone / iPad 用アイコン |

## GitHub Pages で公開する

1. GitHub で新しいリポジトリを作る(Public)。
2. このフォルダのファイルを、すべて同じ階層(ルート)にアップロードする。
3. リポジトリの **Settings → Pages** を開く。
4. **Branch** を `main`、フォルダを `/ (root)` にして Save。
5. 数分後、`https://ユーザー名.github.io/リポジトリ名/` で開けるようになる。

## ホーム画面に追加する

- **iPhone**:Safari で開き、共有ボタン →「ホーム画面に追加」
- **Android**:Chrome で開き、メニュー →「ホーム画面に追加」または「アプリをインストール」

## データについて

- メモはブラウザの `localStorage` に保存されます。ブラウザのデータを消去すると、メモも消えます。
- 端末やブラウザごとに別々です。iPhone では、Safari で開いた場合とホーム画面から開いた場合でデータが分かれます。
- 大事なメモは、書き出し(.txt / .md)で控えを残しておくと安心です。

## 更新するとき

`index.html` を差し替えてコミットするだけで反映されます。反映されないときは、一度アプリを閉じて開き直してください。
